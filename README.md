## 账号被风控，先查 IP 是住宅属性还是机房 IP

亚马逊、TikTok Shop 这类平台的风控会读 IP 属性。机房 IP 的特征太明显：同一段地址几十上百个账号在用，一查就出来。住宅 IP 来自宽带运营商，在平台眼里就是一个普通家庭用户在操作。

比住宅 IP 更进一步的说法是双 ISP。这个词在业内有两种用法，别被宣传页绕进去：

一种是检测层面的。IP 归属数据库里同时显示两个运营商的标注，看起来更像真实家庭宽带。第三方测评者在 LightLayer 台湾机型上跑过 ipinfo 检测，结果判为双 ISP 属性。

另一种是网络层面的。厂商官方博客解释 Dual ISP 时讲的是“提供两个不同运营商的 IP 地址，一条线路出问题时另一条接管”，强调的是冗余和可用性，不是风控层面的纯净度。

两种说法对应的其实是两件事。判断一台机器值不值得买，看检测工具的实际结果，比看宣传词靠谱。

自查动作很简单：开通前问客服要测试 IP，或者开通后立刻用 ipinfo.io 查归属，出现 Hosting、Data Center 字样就要警惕；再用 scamalytics 看欺诈分和滥用分。

## 一店一 IP，成本结构比你想的复杂

原则只有一条：一个店铺对应一个 IP，不能复用。同一个 IP 跑两个账号，等于直接告诉平台这两个号有关联。

5 个店铺就要 5 个 IP。买 5 台最便宜的 VPS 是一种解法，另一种是买一台支持多 IP 的机型。LightLayer 英国那档支持单机 1 到 20 个 IPv4，且是原生本土双 ISP 住宅 IP，一台机器就能覆盖多店铺的 IP 需求，不用堆机器数量，也不用为每台机器单独付一份基础费用。

## 独立站建站是另一条线

同一个“跨境电商vps”搜索词下，混着两类完全不同的需求。做账号运营的人看 IP 属性，做独立站的人看延迟、带宽和支付合规，判断标准几乎不重叠。

行业资讯里对这个问题的分析是：日本机房国际出口带宽充足，连欧美延迟低，适合面向全球市场的卖家；香港机房靠 CN2 GIA 或 BGP 优化，面向中国大陆和东南亚访问更稳，适合用户主要来自内地的站点。合规环境上，日本对电商业务的政策相对开放，香港在跨境结算上有优势但内容监管更严，做敏感类目要提前想清楚。

LightLayer 的香港和日本机房都能覆盖这条线。具体选哪个，看你的访客主要在哪儿：欧美的单多一些，日本；内地和东南亚的单多一些，香港。流量起来之后，两地各放一个节点、用 Nginx 的 GeoIP 模块按来源分流，是行业里被推荐的常见做法。

## 下单前确认这几件事

1. **机房和目标市场是否一致**。做美区选洛杉矶，做英国和欧洲选伦敦，做港台选香港或台湾。
2. **线路档位和你的用途是否匹配**。只看后台、开浏览器，20M 到 50M 够；传视频、跑直播，凑大带宽档。
3. **IP 数量和店铺数量是否对得上**。多店铺优先看支持多 IPv4 的机型，一店一 IP。
4. **指纹浏览器准备好了没有**。服务器只管 IP 层，账号隔离还差这一环。
5. **退款条款能接受吗**。非商家原因不退，先用月付试，别赌年付。
6. **能不能开 Windows**。需要远程桌面操作亚马逊后台的话，开通前问清楚具体机型的系统支持，别默认所有机型都行。
